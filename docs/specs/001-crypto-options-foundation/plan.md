# Technical Architecture & Implementation Plan: Crypto Options Workstation

**Document**: PLAN-001  
**Feature**: SPEC-001 (Crypto Options Workstation Core)

---

## 1. Architectural Strategy

We adhere strictly to the 4-tier clean architecture established in TradePilot:
```
FastAPI Endpoints (Controllers)
       │
Application Services (Orchestration & Workflow)
       │
Domain Layer (Pure Math, Greeks, Risk Checks, Strategy Decisioning)
       │
Repositories & Data Access (SQLAlchemy 2.0 / Alembic)
       │
External Adapters (Deribit Public API, Redis Cache)
```

### Key Domain Principles:
1. **Exchange Independence**: Strategy generation and Greeks calculation have zero dependency on Deribit or exchange-specific schemas. They operate on standard domain models (`OptionContract`, `Greeks`, `OptionChain`, `SpreadPayoff`).
2. **Pluggable Market Data Adapter**: A generic `CryptoMarketDataAdapter` interface with `DeribitMarketDataAdapter` implementation. Can swap or add Binance/OKX in the future without modifying services.
3. **Risk Shield**: All orders generated by strategies or users pass through `RiskEngine.validate_order(...)` before entering the `OrderRepository` or paper execution engine.

## 3. Database Schema Evolutions (Alembic Migration)

### 3.1 New Table: `instruments`
Stores tradable asset definitions, both underlying spot/perps and option contracts:
- `id` (Integer, Primary Key)
- `symbol` (String, Unique, Index, e.g. "BTC-27DEC26-100000-C")
- `underlying` (String, Index, e.g. "BTC", "ETH")
- `instrument_type` (Enum: `SPOT`, `PERP`, `OPTION`)
- `option_type` (Enum: `CALL`, `PUT`, Nullable)
- `strike_price` (Numeric(18, 4), Nullable)
- `expiry_date` (DateTime(timezone=True), Nullable, Index)
- `contract_multiplier` (Numeric(18, 8), Default 1.0)
- `settlement_currency` (String, e.g. "BTC", "USD", "USDC")
- `is_active` (Boolean, Default True)
- `created_at` (DateTime(timezone=True), UTC)

### 3.2 Updates to `orders` and `positions`
- `orders`: Add `client_order_id` (String, Unique, Index for idempotency), `instrument_id` (ForeignKey `instruments.id`, Nullable for backwards compatibility), `parent_order_id` (for multi-leg debit spreads), `limit_price` (Numeric(18, 4)), `execution_price` (Numeric(18, 4)).
- `positions`: Add `instrument_id` (ForeignKey `instruments.id`, Nullable), `delta`, `gamma`, `theta`, `vega` (Numeric(18, 6) snapshot per position).
- `portfolios`: Add `kill_switch_active` (Boolean, Default False), `max_risk_pct` (Numeric(5, 2), Default 1.00).

## 4. API Endpoints Contract

### Market & Options Chain
- `GET /api/v1/crypto/quote?symbol=BTC`
- `GET /api/v1/crypto/history?symbol=BTC&timeframe=1h&period=30d` (Supports `1d`, `4h`, `1h`)
- `GET /api/v1/crypto/options/expiries?underlying=BTC`
- `GET /api/v1/crypto/options/chain?underlying=BTC&expiry=YYYY-MM-DD`

### Greeks & Options Math
- `POST /api/v1/options/greeks`
  - Body: `{ underlying_price, strike_price, time_to_expiry_years, risk_free_rate, volatility, option_type }`
  - Response: `{ price, delta, gamma, theta, vega, rho }`
- `POST /api/v1/options/payoff`
  - Body: Multi-leg or single leg specs.
  - Response: `{ max_profit, max_loss, breakeven_prices, net_debit, risk_reward_ratio, curve: [...] }`
- `POST /api/v1/options/select-candidates`
  - Body: `{ underlying: "BTC", bias: "BULLISH", strategy_type: "BULL_CALL_DEBIT_SPREAD", dte_min: 14, dte_max: 45 }`
  - Response: Recommended contracts with Delta, IV, and liquidity metrics.

### Risk Management
- `POST /api/v1/risk/size-trade`
  - Body: `{ account_equity, max_loss_per_contract, contract_multiplier }`
  - Response: `{ recommended_contracts, total_risk_usd, risk_pct_of_equity, allowed }`
- `GET /api/v1/risk/status`
  - Response: `{ kill_switch_active: bool, account_equity, total_margin_used_pct, daily_pnl }`
- `POST /api/v1/risk/kill-switch`
  - Body: `{ active: true/false, reason: string }`
